# VibeSocket

Use public Vibe.js APIs. Keep browser, Node and Cloudflare dependencies isolated. Never claim delivery beyond the tested protocol stage. Run `pnpm verify` before delivery. Do not publish, push, deploy or create remote resources.

## Git commits

Never add Co-Authored-By, Signed-off-by, Generated-by, or any AI attribution trailers to commit messages. Commit messages contain only the human-authored subject/body. Use Conventional Commits.
